# Support

## Where to Get Help

Use the channel that matches your case.

### 1. GitHub Issues (default)

Use GitHub Issues for:

- Bug reports
- Feature requests
- Documentation gaps
- General usage questions

This is the preferred public support channel for open-source collaboration.

### 2. Private Email (sensitive cases)

Use dev@orca.id for:

- Potential security incidents
- Sensitive operational context not suitable for public issue threads
- Private coordination requests

For vulnerabilities, follow [SECURITY.md](SECURITY.md).

### 3. Community Forum (discussion)

Use https://discourse.orca.id for:

- How-to discussions and implementation ideas
- Community Q&A and best practice sharing
- Non-urgent architecture or operational discussions

Use GitHub Issues when the discussion is actionable and needs tracking as a task.

## Support Boundaries

- Community support is best-effort.
- Maintainers prioritize reproducible issues with clear steps and logs.
- Requests may be redirected to docs at https://docs.orcastra.io when already covered.
- General discussions may be redirected to https://discourse.orca.id.

## Issue Quality Checklist

Before opening an issue, include:

- Orcastra CMP version
- Environment details (OS, Docker, browser)
- Exact steps to reproduce
- Expected vs actual behavior
- Relevant logs or screenshots (with secrets redacted)
