# spice-html5

These scripts are spice-html5 1.7.3 (npm package `spice-html5-bower`), loaded by the graphical
console. Six files carry local changes, tracked in this repository's history: `display.js`,
`inputs.js`, `main.js`, `spiceconn.js`, `spicemsg.js` and `utils.js`. The rest are unmodified.
